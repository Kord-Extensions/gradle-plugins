# Gradle Plugins 1.7.4

This version includes a quick enhancement for the KordEx plugin.

## KordEx Plugin

- Add two new third-party repos (one each for releases and snapshots).
  - These repos will be used by vetted, prolific third-parties to host KordEx tools and libraries they've written on our Maven server.
  - You can disable this by setting `addThirdPartyRepositories` in the `kordEx` builder to `false` if you wish.

More information on this will be forthcoming as we flesh things out.
