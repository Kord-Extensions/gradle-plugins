# Gradle Plugins 1.8.0

This version updates Gradle to version 9.1.0, and switches to Kotlin 2.2.0 for the sake of compatibility.

**Note:** You will need to update your projects to Gradle 9.1.0, otherwise you'll see some strange errors!

## Docker Plugin

- Fix a small issue, which resulted in erroneous configuration cache warnings. The `createDockerfile` task no longer pretends to support the configuration cache.

## KordEx Plugin

- Some compatibility changes in the KSP helper, which now uses KSP task outputs instead of paths to define source-sets, and adds a soft dependency on `kspTestKotlin` to the `jar` task to fix a new build failure.
